## 二、小程序介绍（长文案）

```
免费云同步 · 多因素认证（MFA）工具

【兼容主流验证器】
支持扫描标准 otpauth 二维码导入账号，兼容 Google Authenticator、Microsoft Authenticator、Authy、1Password 等主流验证器导出的迁移二维码。支持 TOTP 与 HOTP，SHA1 / SHA256，6 位与 8 位，30 秒与 60 秒周期，遵循 RFC 6238 / RFC 4226 标准。

【适用场景】
主流网站、邮箱、云服务、游戏、NAS、路由器、服务器 SSH 等开启两步验证（2FA / 双因素 / 二次验证 / 多因素）后的动态验证码生成。

【隐私优先 · 端到端加密】
密钥只保存在你的手机上。同步前用 AES-256-CBC 加密并以 HMAC-SHA256 校验，服务端只保存密文，不持有解密密钥，无法生成或查看你的验证码。无需注册登录，微信内直接使用，不收集手机号、位置、通讯录、相册。

【换机不丢】
退出小程序时自动同步，也可随时手动同步。换手机用「迁移二维码」：旧机生成、新机扫码，全部账号一次接收，迁移码 5 分钟内有效且仅可使用一次。

【其他能力】
分组管理与拖拽排序、搜索、一键复制、到期前显示「下一码」、回收站按删除日期找回、批量导出 JSON 与 otpauth 链接。

【使用提示】
动态密码依赖设备时钟，请开启系统自动对时；密钥等于账号，请勿截图或转发。
```

## 三、提审用「补充说明」

```
本小程序为本地工具类应用，用于生成多因素认证的动态密码（TOTP / HOTP），
兼容标准 otpauth 二维码，不含社交、支付、内容发布等功能。

功能页面：
1. 首页：展示已保存账号的动态密码，支持复制、隐藏、分组筛选、左右滑动切换分组。
2. 添加账号：扫描 otpauth 二维码或手动输入 Base32 密钥，支持 TOTP/HOTP 与高级参数。
3. 设置：云同步、换机迁移二维码、回收站、导出备份、身份授权。
4. 导出：生成本地备份文件与 otpauth 链接。

数据处理：
- 验证码密钥仅保存在用户本机；同步前用 AES-256 加密，服务端只保存密文，
  不持有解密密钥，无法生成验证码。
- 身份识别使用微信 openid（云托管网关注入），不做额外注册登录。
- 头像与昵称仅在用户主动选择后保存，随加密数据一起同步。

测试说明：无需测试账号，微信内直接打开即可使用；身份授权可跳过。
```

## 六、发布前请自行确认

1. **名称**：`双因子密码验证器` 属纯功能描述，官方建议「品牌 + 功能」组合；若被要求整改，
   可改用 `时钥双因子验证器` 这类带品牌词的写法。
2. **品牌词风险**：简介中的 Google / Microsoft 属他人商标。竞品普遍这么写，但理论上存在
   被判「使用他人商标」的可能。想稳妥就用 B 版（只写「标准 otpauth 二维码」）。
3. **不要写**：密码管理器、密码本、保险箱（易判密码管理类目）、银行级/军工级/最安全（夸大）、
   永不丢失（无法保证）。
4. **不要堆关键词**：平台规则明确禁止关键词堆砌，品牌词出现 1 次即可，不要罗列。
