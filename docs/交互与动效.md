# 交互与动效规范

## 一、动效令牌（`app.wxss`）

所有动画统一引用这几个变量，改一处即可全局调整节奏：

```css
--ease:    cubic-bezier(0.22, 0.8, 0.2, 1);   /* 常规进出 */
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);    /* 强出场（翻牌） */
--spring:  cubic-bezier(0.34, 1.32, 0.64, 1); /* 弹性（复制成功） */
--dur-1: 0.16s;   /* 按压反馈 */
--dur-2: 0.26s;   /* 抽屉、弹窗 */
--dur-3: 0.4s;    /* 入场、翻牌 */
```

## 二、动画清单

| 动画 | 用途 | 时长/曲线 |
|---|---|---|
| `rise` | 列表条目入场（stagger 40ms 递增，封顶 280ms） | `--dur-3` / `--ease` |
| `float-in` | 空态、片段浮入 | `--dur-3` / `--ease` |
| `flip` | 验证码到周期后的翻牌（绕顶边 3D） | `--dur-3` / `--ease-out` |
| `pop` | 复制成功的对勾弹出 | `--dur-2` / `--spring` |
| `sheet-up` | 底部抽屉（移动分组、选择迁入分组） | `--dur-2` / `--ease` |
| `dialog-in` | 居中弹窗（迁移二维码） | `--dur-2` / `--ease` |
| `fade` | 遮罩淡入 | 0.2s |
| `tab-in` | 分组 tab 下划线展开（scaleX） | `--dur-2` / `--ease` |
| `breathe` | 分页加载三点呼吸 | 1.1s 循环 |
| `warn-pulse` | 剩余秒数 ≤5 时数字呼吸提示 | 1.6s 循环 |

### 设计原则

1. **一次编排优于多处零散**：入场只在列表首次渲染时错开，不做逐卡 hover 动画。
2. **反馈即因果**：只有用户动作（复制、切换、下拉）才触发动画，不主动播放。
3. **动效不阻塞**：`will-change: transform, opacity` 只加在列表卡片上；不做 layout 属性动画（宽高、top/left），一律用 `transform`。
4. **危险状态常驻提醒**：剩余 ≤5 秒时数字呼吸 + 变红，属于信息而非装饰。

## 三、按压反馈

统一用 `:active` + `transform: scale(0.97~0.99)`，不改变布局：

| 元素 | 缩放 | 附加 |
|---|---|---|
| 列表卡片 `.token` | 0.988 | 透明度 0.96 |
| 圆形图标按钮 `.act` | 0.9 | 颜色转品牌蓝 |
| 复制按钮 `.copy` | 0.94（弹性） | 背景切换 |
| FAB | 0.955 | 展开时旋转 45° |
| 底部主按钮 | 0.985 | — |

## 四、分页与下拉刷新

### 分页

```
pageSize  = 20
page      = 1..n
hasMore   = visible.length < filtered.length
```

- `compute()` 先把过滤后的完整列表算到 `this._filtered`，再由 `applySlice()` 按 `page * pageSize` 切片塞进 `data.list`
- 每秒的 tick 只重算验证码，不重置页码
- 切换分组 / 搜索 / 清除搜索 → `page` 归 1
- 触底加载：`onReachBottom` → `page + 1` → 重新切片，中间留 280ms 让「正在加载」可见

### 下拉刷新

- `index.json` 开启 `enablePullDownRefresh`
- `onPullDownRefresh` 重新读 `store.list()`（回收站恢复、其他页面改动都能立刻反映），重置 `page = 1`，420ms 后 `wx.stopPullDownRefresh()`
- **不触发云端拉取**：云同步仍由「退出自动上传 / 设置页手动同步」负责，避免下拉误覆盖本地未上传的改动

## 五、注意事项

1. 分页只影响渲染，**不影响同步**——同步始终使用 `store.all()` 的完整数据。
2. `setData` 每秒执行一次，因此 `applySlice` 必须保持纯函数、无副作用。
3. 列表使用 `wx:key="id"`，切片变化时未变化的条目会复用节点，不会重播入场动画。
4. 新增动画请复用上表令牌，不要写死秒数，否则调节奏时要改多处。
